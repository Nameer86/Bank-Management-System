# Bank Management System (Python)

A simple command-line Bank Management System developed in Python.

## Features

- Create New Account
- Search Existing Account
- Deposit Money
- Withdraw Money
- Display All Accounts
- Automatic Account Number Generation
- Data Persistence using File Handling

## Technologies Used

- Python
- Dictionaries
- Functions
- Loops
- Conditional Statements
- File Handling
